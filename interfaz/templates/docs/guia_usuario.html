RadProc WEB — Procesador espectral agua/suelo

Guía rápida de usuario — Versión 1.2 (2025)

1. Propósito y alcance

RadProc WEB es una herramienta desarrollada por la Comisión Nacional de Actividades Espaciales (CONAE) para el procesamiento espectral de mediciones radiométricas obtenidas con radiómetros de campo. Permite gestionar campañas de agua y suelo mediante una interfaz web moderna, automatizando la conversión de radiancias a reflectancias, el control de configuraciones y la generación de productos con trazabilidad completa.

Objetivo: ofrecer una plataforma unificada, reproducible y validada para el procesamiento espectral, garantizando coherencia entre los datos de entrada, parámetros configurados y resultados exportados.

2. Flujo general de operación

El flujo básico de trabajo recomendado en RadProc WEB es el siguiente:

  1. Seleccionar el tipo de medición (Agua o Suelo).
  2. Ingresar a Configuraciones para verificar o ajustar parámetros.
  3. Regresar a la pantalla principal y cargar el archivo ZIP de datos.
  4. Opcionalmente, adjuntar un Spectralon de referencia (archivo .txt).
  5. Presionar “Procesar y descargar” para ejecutar el análisis y obtener el ZIP de resultados.
  6. Consultar el área de log para verificar el resultado de la ejecución.
⚠️ Por políticas del navegador, si se carga un archivo ZIP y luego se navega a “Configuraciones”, la referencia del archivo se pierde. Por lo tanto, se recomienda:

1) Seleccionar el tipo de medición.
2) Ajustar las configuraciones necesarias.
3) Cargar el archivo ZIP y ejecutar el procesamiento.

3. Interfaz principal

  • Selector de tipo de medición: define si el conjunto de datos corresponde a agua o suelo. Es el paso obligatorio antes de acceder a las configuraciones.
  • Carga de archivo ZIP: debe respetar la estructura recomendada de carpetas y archivos de medición.
  • Spectralon de referencia (opcional): si se adjunta, se aplicará solo en esa ejecución y no se guardará de forma permanente.
  • Procesar y descargar: inicia el flujo de cálculo y genera automáticamente un archivo ZIP con los productos derivados y los metadatos.
  • Área de log: muestra mensajes del sistema, validaciones y errores.
  • Botones de utilidad:
    • 🧹 Limpiar: reinicia la sesión y elimina configuraciones temporales.
    • ⚙️ Configuraciones: abre el panel de ajustes de parámetros.
    • ☀️🌙 Modo visual: alterna entre modo claro y oscuro.
    • ℹ️ Guía de usuario: abre este documento.

4. Configuraciones y parámetros

El módulo de configuraciones permite ajustar temporalmente los parámetros de procesamiento. Existen tres tipos de configuraciones:

4.1 Agua o Suelo

  • spectrum: cantidad de espectros a promediar por bloque.
  • meas_order: orden de medición (spectralon, target, cielo).
  • target_list: lista de identificadores de mediciones o blancos.

Estas configuraciones afectan directamente la lógica de procesamiento. Los cambios se aplican solo en la siguiente ejecución y se almacenan en sesión, por lo que se eliminan al presionar “Limpiar”.

4.2 Spectralon (referencia)

La opción Spectralon permite editar o sustituir el archivo de referencia utilizado para calcular las reflectancias. Hay dos modos posibles:

  • Edición parcial: se pueden modificar únicamente algunos parámetros del archivo Spectralon por defecto.
  • Reemplazo completo: permite subir un nuevo archivo Spectralon (.txt) temporal que será usado solo durante la ejecución actual.
⚙️ Las configuraciones del tipo Spectralon no alteran el archivo base permanente del sistema, sino que se aplican de forma temporal a la sesión actual.

5. Procesamiento, resultados y registro de ejecución

Al presionar Procesar y descargar, el sistema envía los datos al servicio principal (interfaz/services/processing.py), que comunica la solicitud al módulo central de procesamiento (procesamiento/service.py).

  • Verifica el tipo de medición y la validez del archivo ZIP.
  • Aplica los parámetros definidos y el Spectralon correspondiente.
  • Ejecuta los cálculos radiométricos y genera los productos derivados.
  • Comprime los resultados y devuelve un archivo ZIP (resultados_agua.zip o resultados_suelo.zip), que incluye todos los productos y un registro detallado de la ejecución.

Durante este proceso, el sistema mantiene un registro técnico interno (log) con información completa sobre la sesión:

  • Tipo de medición procesada (agua o suelo).
  • Parámetros y configuraciones aplicadas.
  • Nombre del Spectralon utilizado.
  • Archivos procesados y estructura de entrada.
  • Tiempos de ejecución, validaciones y posibles advertencias.
🧾 Este log se guarda automáticamente dentro del ZIP de resultados en formato JSON, lo que permite conservar trazabilidad técnica y reproducibilidad de cada ejecución.

6. Logs, trazabilidad y funciones futuras

Además del registro interno incluido en el ZIP, la interfaz presenta un área de log visual que muestra en tiempo real los mensajes del proceso: inicio, ejecución y finalización. Esta información es solo referencial y no reemplaza al log técnico.

  • Log técnico (interno): archivo .json dentro del ZIP generado, con todos los datos técnicos de la sesión. Es el registro oficial para control y auditoría.
  • Log visual (pantalla): muestra los eventos principales durante la ejecución.
  • Botón “🔧 Próxima función”: reservado para futuras implementaciones. Actualmente informa al usuario que la funcionalidad se encuentra en desarrollo.
🧩 En futuras versiones, este botón podrá incorporar funciones adicionales, como:
• Generar un informe resumido de procesamiento (PDF o TXT).
• Enviar registros a un servidor interno para monitoreo.
• Comparar configuraciones entre ejecuciones previas.

Se recomienda conservar los archivos ZIP de resultados con su log interno como respaldo técnico de cada campaña.

7. Estructura de datos recomendada

Las carpetas de entrada deben respetar la siguiente estructura:

Mediciones de AGUA

123-20240513-SUS/
    Radiometria/
        Texto Rad CorrPar/
            *.txt

Mediciones de SUELO

183-20220816-SG/
    Radiometria/
        Texto Rad CorrPar/
            *.txt

Los nombres siguen el patrón código-fecha-identificador, fundamental para la correcta identificación de cada conjunto de datos.

8. Errores comunes y recomendaciones

  • Tipo de medición inválido: asegúrese de seleccionar “Agua” o “Suelo” antes de procesar.
  • Archivo ZIP faltante: el campo es obligatorio.
  • Archivo Spectralon demasiado grande: reduzca el tamaño o use el predeterminado.
  • Archivo perdido tras cambiar de vista: vuelva a cargar el ZIP antes de procesar.
  • Error de procesamiento: revise el log; puede deberse a estructura o formato incorrecto.
